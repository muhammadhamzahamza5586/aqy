# Personal portfolio starter

A simple, responsive portfolio built with plain HTML, CSS, and JavaScript. No build step or dependencies are required.

## Make it yours

1. Open `index.html` and replace **Your Name**, the intro, and project descriptions with your own details.
2. Replace each `hello@example.com` address with your email.
3. Update the project links in the Selected Projects section to point to your live projects.
4. Open `index.html` in a browser to preview the site.

## Publish with GitHub and Vercel

1. Create a new repository on [GitHub](https://github.com/new).
2. In the new repository, choose **Add file → Upload files**. Upload `index.html`, `style.css`, `script.js`, and `README.md`, then commit the files.
3. Sign in to [Vercel](https://vercel.com) with GitHub and choose **Add New → Project**.
4. Import your repository and select **Deploy**. Vercel will detect the static site automatically; no build command or output directory is needed.
5. After deployment, you can update the site by uploading and committing changed files to GitHub. Vercel will redeploy automatically.
